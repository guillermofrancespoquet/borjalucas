PROPÓSITO
─────────
Crear un estándar visual consistente para todas las planificaciones nutricionales
de clientes en NUTRILOGOS. Cada cliente tendrá su contenido único pero con la
misma estructura HTML, CSS y distribución visual.
 
Cada planificación consta de estos bloques en orden:
  1.  Cabecera: título + subtítulo
  2.  Descripción del cliente (píldoras)
  3.  Objetivo (bloque azul)
  4.  Perfil de la persona (métricas, somatotipo, antropometría, bioimpedancia, impresiones)
  5.  Tabla resumen semanal (vista de un vistazo)
  6.  Menú desarrollado por días (tabs interactivos)
  7.  Lista de compra semanal (tabs interactivos con tachado)
  8.  Suplementación recomendada (si aplica)
  9.  Recetas (acordeón expandible, si aplica)
  10. Sección personalizada por cliente (si aplica — ver Sección 10)
  11. Próxima revisión

NOTAS IMPORTANTES DE ESTRUCTURA:
- NO usar <hr> entre secciones. El separador visual es únicamente el border-bottom del .section-label.
- NO usar border-top ni padding-top en los wrappers de sección. Solo margin-top:2.5rem.
- El único elemento que tiene borde inferior es .section-label (ver CSS, Sección 2).
 
NOTA BOTÓN CALENDARIO: Si no hay fecha exacta, añadir al enlace `pointer-events:none;opacity:0.4;` para que
se vea inactivo. Formato de fechas UTC: YYYYMMDDTHHMMSSZ (ej: 20260602T100000Z).

        type: "D",          // D | A | C | Me | Ce  (A = Almuerzo/media mañana, OPCIONAL, solo si el cliente la lleva)

];

<script>

function badgeClass(type, libre) {
  if (libre) return "badge-libre";
  const map = { D:"badge-d", A:"badge-a", Me:"badge-me", C:"badge-c", Ce:"badge-ce" };
  return map[type] || "badge-c";
}
function badgeLabel(type, libre) {
  if (libre) return "Libre";
  const map = { D:"Desayuno", A:"Almuerzo", Me:"Merienda", C:"Comida", Ce:"Cena" };
  return map[type] || type;
}
 
let current = 0;
 
function render() {
  const d = days[current];
  let html = `<div style="font-size:18px;font-weight:500;color:#111;margin-bottom:8px">${d.full}</div>`;
  html += `<div class="pn-sport-banner ${d.sportClass}">${d.sport} — ${d.sportBanner}</div>`;
  if (d.libre) html += `<div class="pn-libre-banner">La cena de este día está reservada como comida libre. El resto del día mantiene la base vegetal habitual.</div>`;
  if (d.suppl) html += `<div class="pn-supp-banner">` + d.suppl.replace(/\n/g,"<br>") + `</div>`;
  if (d.batchCooking) {
    const bc = d.batchCooking;
    const items = bc.items.map(i => `<li>${i}</li>`).join("");
    html += `<div class="pn-batch-section"><h3>${bc.title}</h3><ul>${items}</ul><div class="bc-note">⏱ ${bc.note}</div></div>`;
  }
  html += `<div class="pn-meals">`;
  d.meals.forEach(m => {
    const bc = badgeClass(m.type, m.libre);
    const bl = badgeLabel(m.type, m.libre);
    let tagsHtml = "";
    if (m.tags && m.tags.includes("extra")) tagsHtml += `<span class="pn-extra-tag">🥡 Hacer cantidad extra</span> `;
    if (m.tags && m.tags.includes("batch")) tagsHtml += `<span class="pn-batch-tag">♻️ Usar del batch cooking</span> `;
    const rawParts = m.desc.split(/\n/).map(s => s.trim()).filter(s => s.length > 0);
    let ingsHtml = rawParts.map(part => `<span class="pn-ing">${part}</span>`).join("");
    html += `
      <div class="pn-card">
        <div class="pn-meal-header">
          <span class="pn-badge ${bc}">${bl}</span>
          <span class="pn-time">${m.time}</span>
        </div>
        ${tagsHtml ? `<div style="margin-bottom:6px">${tagsHtml}</div>` : ""}
        <div class="pn-name">${m.name}</div>
        <div class="pn-ing-list">${ingsHtml}</div>
        <div class="pn-note">Adaptación: ${m.note}</div>
      </div>`;
  });
  html += `</div>`;

}
 
function buildTabs() {
  const container = document.getElementById("dayTabs");
  days.forEach((d, i) => {
    const btn = document.createElement("button");

      document.querySelectorAll(".pn-day-btn").forEach(b => b.classList.remove("active"));
      btn.classList.add("active");
      current = i;
      render();
    };
    container.appendChild(btn);
  });
}
 
let shopCurrent = 0;

  const cat = shopCategories[shopCurrent];

## 10. SECCIÓN PERSONALIZADA POR CLIENTE
 
Esta sección es OPCIONAL y COMPLETAMENTE FLEXIBLE. Se incluye cuando el cliente
tiene un contexto específico que requiere información adicional estructurada
más allá del plan nutricional estándar.
 
El sistema de tarjetas con iconos de estado sirve para CUALQUIER tipo de contenido
secuencial, temporal o con seguimiento de estado. No está limitado a pruebas físicas.
 
Ejemplos de uso posible:
- Opositor (bombero, policía, militar): calendario de pruebas y fases nutricionales
- Deportista con temporada: partidos, competiciones, objetivos por fase
- Hidratación deportiva: pautas antes / durante / después del partido o entreno
- Pautas nutricionales especiales: fases de carga, días de descanso, viajes
- Protocolo de recuperación: semanas post-lesión, reintroducción progresiva
- Analítica sanguínea: seguimiento de marcadores en el tiempo
- Cualquier secuencia de eventos con estado (completado / próximo / pendiente / no logrado)
 
La sección siempre se inserta ANTES de "Próxima revisión" y DESPUÉS de Recetas.
Usar el mismo patrón de sección: margin-top:2.5rem + section-label descriptivo y personalizado.
 
### Sistema de iconos de estado (universal)
 
Los iconos se usan en cualquier tarjeta que requiera indicar el estado de un ítem:
 
- ✅ → Completado / ejecutado / superado / logrado
       Fondo: #f0faf5   Borde: #b8e6d0
- 🔵 → Próximo / inminente / en curso / activo
       Fondo: #EBF3FB   Borde: #A8C8E8
- ⬜ → Pendiente / futuro / no iniciado
       Fondo: #f7f7f7   Borde: #e0e0e0
- ❌ → No logrado / cancelado / descartado (usar con criterio)
       Fondo: #fdf0f0   Borde: #f4b8b8
 
El significado exacto de cada icono se adapta al contexto:
- Pruebas de oposición: ✅ superada · 🔵 próxima · ⬜ pendiente · ❌ no superada
- Partidos / competición: ✅ jugado · 🔵 próximo · ⬜ pendiente · ❌ suspendido
- Pautas / protocolos: ✅ ejecutado · 🔵 en curso · ⬜ pendiente · ❌ descartado
- Marcadores analítica: ✅ normalizado · 🔵 mejorando · ⬜ pendiente revisión · ❌ fuera de rango
